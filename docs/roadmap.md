## M6+: 上规模才考虑 (Month 3+)

**触发条件满足时才做**:

| Feature | 触发条件 |
|---------|----------|
| Cal.com 自动排期 | 顾问每天手动约浪费 > 1h |
| 企业微信迁移 | 顾问个人微信好友超 3000 |
| 支付宝当面付 | 微信失败转化损失 > 5% |
| 客户自助查订单 | "我那个文档呢" > 5 次/周 |
| Tair Redis 启用 | 真实恶意流量 / 多副本 scale |
| 多租户企业账号 | 大客户要求"多人共用 credits" |
| Webhook 提供给客户 | 客户主动问"能不能集成" |
| API Key 开放 | 单客户付费 > 5万/年 |
| 迁自建队列 | Edge Functions 并发/成本不满足 |
| 国内 region 多活 | 上海单 region 故障 > 4h |
