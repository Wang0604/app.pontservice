## 一、关于那笔 ¥1600 的分析

你提到"阿里云的认证，包括一个网关、一个网址加上一个 App，需要 1600 元"。

### 1.1 推测组成

我没看购物车，但根据经验，这个捆绑最可能是以下组合:

| 项 | 推测价格 | 现在需要吗？ |
|---|---------|------------|
| OV 型 SSL 证书 | ¥1000-2000/年 | ❌ 不需要（DV 证书免费，够 MVP） |
| 阿里云 API 网关 | ¥几十/月起 | ❌ 不需要（Next.js 自带 API Routes） |
| App 企业开发者认证 | ¥300-500 | ❌ 不需要（你做的是 Web App，不是原生 App） |
| 阿里云域名（新买） | ¥几十-几百 | ❌ 不需要（`pontai.cloud` 已有） |
| 阿里云备案"幕布"等附加物 | 本身免费，但有代拍服务 | ❌ 不需要（Stage 0 不备案） |

### 1.2 为什么判断是销售捆绑

1. **阿里云企业实名认证本身免费** —— 只需上传营业执照，阿里云审核 1-3 工作日通过，零费用
2. **ICP 备案本身免费** —— 阿里云代备案服务也免费
3. **DV 证书（Domain Validated）免费** —— 阿里云提供免费 SSL 证书
4. **1600 整数价格** —— 典型的销售打包价（¥1888 / ¥1600 / ¥999 这类整数）

结论: **这笔钱 100% 不需要花**。如果是 OV/EV 证书+企业增值服务捆绑，Stage 0 根本用不到；如果真的是"企业认证"，那是销售话术欺诈，应该投诉。

### 1.3 Stage 0 的 SSL 方案

**Cloudflare 自动签发 Let's Encrypt SSL 证书**（免费，自动续期），`pontai.cloud` DNS 托管到 Cloudflare 后自动有 HTTPS。Railway 的原始域名也自带 HTTPS。**零成本零工作量**。

未来 Stage 2 国内域名 `pontai.com`，阿里云 CDN 配免费 DV 证书即可，也不需要 OV/EV。

**OV/EV 证书只有银行、政府、大企业官网才真的需要**。

## 三、现在准备（🟡）

这些不花钱，但 Stage 2 要用，提前归档能省很多时间:

### 3.1 公司主体材料归档

在一个安全的云盘（如 1Password / Dropbox 加密目录）建立文件夹 `legal-and-registration/`，归档:

- [ ] 公司 A 营业执照扫描件（彩色，高清）
- [ ] 公司 B 营业执照扫描件
- [ ] 两家公司的法人身份证正反面
- [ ] 两家公司的对公账户信息（开户行、账号、户名）
- [ ] 两家公司的公章 + 财务章扫描件
- [ ] 法人数字签名（用于电子合同）

### 3.2 域名规划

- [ ] 确认 `pontai.cloud` 作为**海外主域名**长期保留
- [ ] 预留 `pontai.com` 或 `pontai.cn`（Stage 2 用于国内域名，现在可以买下来避免抢注）
  - 建议: **今天就买** `pontai.com`，成本 ¥55-90/年，防止被人抢注，备案也优先
  - **注**: `.com` 需要实名认证，用任一家公司主体注册即可
  - **注**: 不要买 `.cn`，备案比 `.com` 略严格，且全球认知度低于 `.com`

### 3.3 未来备案预演

Stage 2 启动 ICP 备案时要提交的材料（现在不交，但收集齐):

- [ ] 选定用于备案的公司主体（建议选业务主体清晰、纳税正常的那家）
- [ ] 营业执照、法人证件、网站负责人证件（可同法人）
- [ ] 准备好"网站负责人半身照"拍摄环境（阿里云 APP 内拍，要求白背景，到时候再拍）
- [ ] 提前了解"前置审批"（医疗/教育/金融类需要）——你的工具类不需要前置审批，确认即可

### 3.4 商户号预演

Stage 2 启动微信支付商户号时要提交的材料:

- [ ] 公司营业执照（与 ICP 备案同一主体）
- [ ] 对公账户（需要"对公打款验证"）
- [ ] 商户简称（建议: "Pontai 数智服务" 或 "999 工具库"）
- [ ] 经营类目（选"信息技术服务"）
- [ ] 超级管理员信息（法人或指定员工）

### 3.5 发票系统预演

- [ ] 确认公司税务主体（小规模纳税人 / 一般纳税人）
- [ ] 申请开票软件（税务局指定，不同地区不同）
- [ ] 准备发票抬头模板（客户给到什么开什么）

## 四、Stage 2 启动（🟢）

**触发条件**: 满足 [stage-plan.md](stage-plan.md) 中 Stage 2 的进入条件后

**启动时的检查清单**:

### 4.1 关键路径依赖（提前 20-30 工作日启动）

- [ ] 阿里云企业实名认证（1-3 工作日）
- [ ] `pontai.com` ICP 备案（20 工作日）
- [ ] 微信支付商户号开户（7-15 工作日）
- [ ] 支付宝开放平台认证（3-7 工作日）

### 4.2 基础设施开通（企业认证通过后）

- [ ] AnalyticDB Supabase 实例（上海）
- [ ] 阿里云 SAE（dev + prod 命名空间）
- [ ] VPC 配置（Supabase 和 SAE 同一 VPC）
- [ ] 阿里云短信（签名 + 模板审批）
- [ ] 阿里云邮件推送 DM
- [ ] 阿里云 CDN + WAF（备案通过后）
- [ ] 阿里云 SLS 日志
- [ ] 阿里云云监控

### 4.3 代码双轨化

- [ ] `NEXT_PUBLIC_REGION` 环境变量驱动供应商切换
- [ ] Provider 抽象层添加阿里云实现（`AliyunSmsProvider` / `AliyunStorageProvider` 等）
- [ ] 数据库迁移脚本（可能需要从 Supabase 官方迁到阿里云版）
- [ ] 支付 Provider 增加 `WeChatPayProvider` / `AlipayProvider`

### 4.4 数据迁移策略

**两种选项**:

**选项 A: 所有数据迁到阿里云版（海外域名也用上海机房）**
- 优势: 单一数据源，管理简单
- 劣势: 海外用户访问上海机房延迟高

**选项 B: 数据分区（海外用户在新加坡，国内用户在上海）**
- 优势: 用户体验最优
- 劣势: 复杂度高，跨区迁移工具要写

**建议**: Stage 2 初期用 B，等规模大了评估是否合并。

## 五、阿里云 vs 非阿里云选型总结

这张表是你面对"该不该用阿里云 XX"时的决策指南（严格继承前 CTO v1.1）:

| 需求 | Stage 0/1 选型 | Stage 2 选型 | 理由 |
|------|-------------|-------------|------|
| 部署 | **Railway** | Railway（海外）+ 阿里云 SAE（国内） | 都是 Docker，同构迁移 |
| 数据库 | **Railway PostgreSQL** | Railway PG（海外）+ AnalyticDB Supabase（国内） | 标准 PG 协议 |
| 文件存储 | **Cloudflare R2** | R2（海外）+ 阿里云 OSS（国内） | S3 协议兼容 |
| CDN + DNS + WAF | **Cloudflare** | Cloudflare（海外）+ 阿里云 CDN（国内） | 各取所长 |
| Auth | **Better Auth** | Better Auth（海外）+ Supabase Auth（国内） | 迁移时写脚本 |
| 异步任务 | **Inngest** | Inngest（海外）+ pg_cron（国内，合规） | 视 Stage 2 合规要求 |
| 邮件 | Resend | Resend（可跨区用） | Resend 质量好 |
| 短信 | Stage 0 不用 | 阿里云短信（国内用户） | 国内短信便宜 |
| SSL | Cloudflare 自动 | Cloudflare + 阿里云免费 DV | 零成本 |
| 日志 | Railway Logs | Railway + 阿里云 SLS（国内补充） | 先用平台自带 |
| 错误监控 | 延后 | 需要时接（Sentry / BetterStack / SLS） | 真出事故再决定 |
| 产品分析 | 延后 | 需要时接（PostHog / Plausible / ARMS） | 真要做漏斗分析再决定 |
| OCR | DeepSeek | DeepSeek（两边都能用） | 境内外可直连 |
| LLM | Anthropic + DeepSeek | Anthropic（海外）+ 火山方舟（国内合规） | Provider 抽象层切换 |
| 支付 | 对公转账 | + 微信支付 + 支付宝 + Stripe | 多渠道 |

## 六、如果你还是想现在花钱买阿里云，我的建议

如果出于某些原因（比如已经付款、销售关系、财务考量）必须现在走阿里云:

1. **最小化**: 只开 AnalyticDB Supabase（免费版 1C2G），其他一律不开
2. **不买 OV/EV 证书**: DV 免费证书够 MVP
3. **不买企业认证增值服务**: 实名认证本身免费
4. **不提前囤备案**: `.cloud` 备案审核被拒的风险高，浪费 20 工作日
5. **不买阿里云域名**: 已有 `pontai.cloud`，阿里云域名是额外支出

**但我作为 CTO 的最强建议是**: **那 ¥1600 现在一分都不要花**，等 Stage 2 触发时再做决策。
