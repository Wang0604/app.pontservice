## ⚠️ 常见坑与检查

### 坑 1: 域名备案被拒
**症状**: `.cloud` / `.xyz` 等新顶级域备案被拒
**对策**: 立即买 `.com` 备用，两手准备

### 坑 2: 微信支付商户号审核慢
**症状**: 材料不全被打回，又要等 7 天
**对策**: 今天一次性准备齐所有材料

### 坑 3: 阿里云短信模板被拒
**症状**: 模板内容不合规 (如没加退订)
**对策**: 严格按照阿里云短信模板规范写

### 坑 4: Supabase 连不上
**症状**: 本地开发连 Supabase 超时
**对策**: 确认使用的是公网连接串，内网连接串只能在阿里云 VPC 内用

### 坑 5: Edge Function 冷启动慢
**症状**: 第一次调用 Edge Function 超时
**对策**: 这是正常的，MVP 阶段接受，上量后考虑 Keep-warm
